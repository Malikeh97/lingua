================================================================================
TROUBLESHOOTING
================================================================================

OOM Error:
  - Edit smoke_test_1b.yaml: set data.batch_size: 1
  - Or reduce data.max_encoder_len: 512

Slow Data Loading:
  - SQuAD downloads on first run (~5 min)
  - Set data.num_workers: 0 to debug

NCCL Timeout:
  - Add to SLURM script: export NCCL_TIMEOUT=3600
