================================================================================
                    MVP Encoder-Decoder Training Guide
================================================================================

This guide explains how to run the MVP encoder-decoder model with a frozen
pretrained encoder (ModernBERT) and a trainable decoder.

================================================================================
OVERVIEW
================================================================================

The MVP consists of:
- Encoder: Frozen ModernBERT-base (149M params) - embeds retrieved documents
- Decoder: Trainable 6-layer transformer (~100M params) - generates answers
- Cross-attention: Standard softmax attention (quadratic, but proven)

Two encoder modes are available:
1. "pretrained" - Uses frozen ModernBERT (recommended for MVP)
2. "embedding_only" - Uses decoder embeddings only (for quick debugging)

================================================================================
PREREQUISITES
================================================================================

1. Ensure you have access to the lingua environment:

   source /home/ehghaghi/scratch/ehghaghi/envs/lingua_env/bin/activate

2. Required packages (should already be installed):
   - torch
   - transformers (for ModernBERT)
   - datasets (for SQuAD)
   - flash-attn (optional, for faster attention)

3. Verify transformers is installed:

   python -c "import transformers; print(transformers.__version__)"

================================================================================
STEP 1: PREPARE DIRECTORIES
================================================================================

Create the output directories:

   mkdir -p /home/ehghaghi/scratch/ehghaghi/mvp_modernbert/logs
   mkdir -p /home/ehghaghi/scratch/ehghaghi/.cache/huggingface

================================================================================
STEP 2: (OPTIONAL) PRE-DOWNLOAD MODELS
================================================================================

To avoid download delays during training, pre-download ModernBERT:

   python -c "
   from transformers import AutoModel, AutoTokenizer
   print('Downloading ModernBERT-base...')
   tokenizer = AutoTokenizer.from_pretrained('answerdotai/ModernBERT-base')
   model = AutoModel.from_pretrained('answerdotai/ModernBERT-base')
   print('Done!')
   "

================================================================================
STEP 3: RUN TRAINING
================================================================================

Option A: Submit as SLURM job (recommended for full training)
-------------------------------------------------------------

   cd /project/6104653/ehghaghi/lingua
   sbatch apps/enc_dec/submit_mvp_modernbert.slurm

Monitor the job:

   squeue -u $USER                    # Check job status
   tail -f /home/ehghaghi/scratch/ehghaghi/mvp_modernbert/logs/mvp_modernbert_*.out


Option B: Run interactively (for debugging)
-------------------------------------------

First, get an interactive GPU session:

   salloc --partition=gpubase_l40s_b3 --gres=gpu:l40s:1 --cpus-per-task=16 \
          --mem=250GB --account=aip-craffel --time=02:00:00

Then run:

   module load cuda/12.6
   module load gcc arrow/19.0.1 python/3.11
   source /home/ehghaghi/scratch/ehghaghi/envs/lingua_env/bin/activate

   cd /project/6104653/ehghaghi/lingua

   torchrun --nproc-per-node 1 --master-port 29500 \
       -m apps.enc_dec.train \
       config=apps/enc_dec/configs/mvp_modernbert.yaml


Option C: Quick test with embedding-only encoder
------------------------------------------------

For faster debugging without downloading ModernBERT:

   torchrun --nproc-per-node 1 --master-port 29500 \
       -m apps.enc_dec.train \
       config=apps/enc_dec/configs/mvp_embedding_only.yaml

================================================================================
STEP 4: MONITOR TRAINING
================================================================================

Training logs are written to:
- Console output: /home/ehghaghi/scratch/ehghaghi/mvp_modernbert/logs/
- Metrics file: /home/ehghaghi/scratch/ehghaghi/mvp_modernbert/metrics.jsonl
- Config dump: /home/ehghaghi/scratch/ehghaghi/mvp_modernbert/config.yaml

Key metrics to watch:
- loss/out: Training loss (should decrease)
- optim/grad_norm: Gradient norm (should be stable, <10)
- speed/wps: Words per second (throughput)
- memory/max_active_pct: GPU memory usage

View live metrics:

   tail -f /home/ehghaghi/scratch/ehghaghi/mvp_modernbert/metrics.jsonl | \
       python -c "import sys,json; [print(f\"step={json.loads(l).get('global_step',0)} loss={json.loads(l).get('loss/out',0):.4f}\") for l in sys.stdin]"

================================================================================
STEP 5: CHECKPOINTS
================================================================================

Checkpoints are saved to:
   /home/ehghaghi/scratch/ehghaghi/mvp_modernbert/checkpoints/

Checkpoint schedule (from config):
- Every 200 steps: Training checkpoint (keep last 3)
- Every 500 steps: Evaluation checkpoint (keep last 2)

To resume from checkpoint, the training script automatically loads the latest
checkpoint if it exists.

================================================================================
CONFIGURATION OPTIONS
================================================================================

Key parameters in mvp_modernbert.yaml:

Model:
  model.dim: 768                    # Must match ModernBERT hidden dim
  model.encoder_type: pretrained    # Use frozen pretrained encoder
  model.pretrained_encoder.model_name: answerdotai/ModernBERT-base
  model.decoder.n_layers: 6         # Decoder depth

Data:
  data.max_encoder_len: 1024        # Max document length
  data.max_decoder_len: 256         # Max question+answer length
  data.batch_size: 4                # Batch size per GPU
  data.encoder_tokenizer_name: answerdotai/ModernBERT-base

Training:
  steps: 1000                       # Total training steps
  grad_acc_steps: 4                 # Gradient accumulation
  optim.lr: 3e-4                    # Learning rate

Override any parameter via command line:

   torchrun ... -m apps.enc_dec.train \
       config=apps/enc_dec/configs/mvp_modernbert.yaml \
       steps=500 \
       data.batch_size=2 \
       optim.lr=1e-4

================================================================================
TROUBLESHOOTING
================================================================================

1. "ModuleNotFoundError: No module named 'transformers'"

   Install transformers:
   pip install transformers>=4.48.0

2. "CUDA out of memory"

   Reduce batch size or sequence length:
   data.batch_size=2 data.max_encoder_len=512

3. "Connection error downloading model"

   Set HuggingFace cache and retry:
   export HF_HOME=/home/ehghaghi/scratch/ehghaghi/.cache/huggingface
   export HUGGINGFACE_HUB_CACHE=$HF_HOME

4. "Flash attention not available"

   ModernBERT will fall back to standard attention. To enable flash attention:
   pip install flash-attn --no-build-isolation

5. Slow data loading

   Reduce num_workers or prefetch_factor:
   data.num_workers=2 data.prefetch_factor=1
